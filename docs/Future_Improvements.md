# Future Improvements Backlog

The following ideas have been brainstormed for future implementation to further elevate the Kosan Fio system into a complete ERP/POS:

### 1. Multi-Role Employee Access (RBAC)
- **Concept:** Create distinct login roles (e.g., Admin vs. Kasir).
- **Benefit:** Staff can process rentals and returns without having permission to delete records, edit pricing, or view high-level financial dashboards. Protects against internal tampering.

### 2. Barcode / QR Code Scanning
- **Concept:** Generate a unique QR code for physical Rooms or embed them in the generated PDF Kwitansi (Receipts).
- **Benefit:** When a customer returns a dress, staff simply scan the receipt to instantly pull up the rental record instead of manually searching.

### 3. Financial Accounting (Laporan Arus Kas)
- **Concept:** Expand the financial tracking beyond just revenue. Allow staff to input operational expenses (e.g., laundry costs, boutique rent, purchasing new room).
- **Benefit:** The dashboard can automatically calculate Net Profit (Laba Bersih) instead of just Gross Income.
